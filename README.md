# Kafé Kardemumma

En responsiv webbplats för ett fiktivt kafé i hjärtat av Stockholm. Här kan besökare utforska kaféets meny, läsa om verksamheten och boka bord.

## Live Demo

[Besök Kafé Kardemumma](https://onakt.github.io/onur-m4-dag10-github-och-publicering/)

## Funktioner

- Presentation av Kaféet
- Meny med produkter och priser
- Information om kaféet och öppettider
- Navigering mellan olika sektioner
- Separat kontaktsida för bordsbokning

## Tekniker

- HTML5
- CSS3
- CSS Variables
- Flexbox
- CSS Grid
- Responsiv webbdesign
- Git och GitHub
